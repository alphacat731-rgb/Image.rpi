# Changelog

## 0.1.0 — 2026-09-28

- Initial IMAGE.RPI terminal viewer.
- Added background image loading with progress events.
- Added six image-quality presets.
- Added white-canvas ANSI/Unicode renderer with truecolor and 256-color paths.
- Added directory browser, image metadata overlay, help overlay and keyboard navigation.
- Added EXIF orientation handling and transparent-image compositing.
- Added Debian Trixie-oriented installer and tests.
